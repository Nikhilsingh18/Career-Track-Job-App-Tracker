# CareerTrack — Full Website Starter

CareerTrack is a responsive, career and placement dashboard built with HTML, CSS, and vanilla JavaScript. 

# Features included now

- Responsive dashboard and mobile navigation
- Job listing cards with sample/demo opportunities
- Search by role, company, location, or skill
- Filters for job type, location, and experience
- Save/unsave jobs; saved jobs persist with `localStorage`
- Application tracker: add, filter, and delete applications
- Dashboard stats for jobs, saved jobs, applications, and interviews
- Placement checklist with saved completion state
- Weekly preparation tracker
- Links to external job and learning resources
- Accessible labels, empty states, and confirmation toasts

## Important limitations

- Job openings are **sample data**. The links go to general job-search websites, not verified individual vacancies.
- Data is stored in this browser only. Clearing browser storage removes saved jobs, applications, and progress.
- There is no account/login system, shared database, live job API, email alert, or admin panel yet.
- Never enter passwords or sensitive personal information in this demo.

## Project files

- `index.html` — page structure
- `style.css` — responsive styling
- `script.js` — demo data, rendering, filters, and browser storage
